# PLEGMA
Authors: [K. Hadjannakou](https://github.com/khadjiyiannakou), [S. Bacchio](https://github.com/sbacchio), [D. Nole](https://github.com/davidenole), [S. Paul](https://github.com/srijitpaul)

PLEGMA is a GPU-enabled, memory distributed software package for lattice QCD calculations. It is developed for use by the Cyprus lattice QCD group within projects of the Extended Twisted Mass Collaboration (ETMC), implementing:
- Two point correlation functions for hadrons
- Nucleon Three point correlation functions
- Nucleon quasi Parton Distribution functions
- Disconnected quark loops
- Topological charge calculation with fermionic definitions

## Usage
To use PLEGMA in a new project contact [K. Hadjiyiannakou](https://github.com/khadjiyiannakou) or [G. Koutsou](https://github.com/g-koutsou)
